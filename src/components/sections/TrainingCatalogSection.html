Training

A Comprehensive Training Curriculum

Tailored to different business roles, with learning paths designed around each role’s specific needs and workflows.

TRAINING MODULE CATALOG
MODULE 01 · KNOWLEDGE FABRIC

Build the business semantic foundation

Turn fragmented business materials into understandable, verifiable and reusable enterprise semantic assets.

◇TRAINING FOCUS
  1. Organize business materials, processes, rules, interface documentation and sample data
  2. Manage knowledge sources through the Knowledge Base and Resource Library
  3. Understand business objects, properties, relationships, rules, actions and instance facts
  4. Build, inspect and validate an Ontology with full source traceability
  5. Manage knowledge scope, versions, business definitions and conditions of use
  6. Identify missing materials, rule conflicts, inconsistent definitions and open questions
MODULE 02 · AI MARKETPLACE

Publish, discover and govern capabilities

Create a clear capability catalog so Agents, Skills, MCP Servers, APIs and Tools can be reused safely.

◇TRAINING FOCUS
  1. Understand Marketplace asset types, positioning and usage boundaries
  2. Create clear capability descriptions, tags, inputs, outputs and examples
  3. Publish, search, trial, subscribe to and reuse enterprise capabilities
  4. Configure visibility, access rights, credentials and invocation quotas
  5. Manage version upgrades, dependencies, compatibility and retirement
  6. Track capability usage through approval records and audit information
MODULE 03 · AGENT FACTORY

Build, test and publish Agents

Combine knowledge, capabilities, instructions and safety boundaries into an operational Agent built around a business goal.

◇TRAINING FOCUS
  1. Define the Agent goal, role, task scope and responsibility boundaries
  2. Connect the Ontology, business rules and required context
  3. Select and configure Skills, Tools, APIs and MCP Servers
  4. Design instructions, workflows, inputs, outputs and exception handling
  5. Create test cases for accuracy, safety and explainability
  6. Publish versions, observe runs, diagnose issues and continuously improve
MODULE 04 · ITEMGPT

A unified entry point for business users

Start business tasks in natural language, understand Agent execution and confirm critical results with human judgment.

◇TRAINING FOCUS
  1. Navigate workspaces, conversations, the Agent catalog and common actions
  2. Express business goals, context, constraints and expected results clearly
  3. Select the right Agent and understand multi-Agent collaboration
  4. Inspect sources, tool calls, execution status and exception messages
  5. Apply human confirmation to high-risk actions and critical results
  6. Save, share and export results while submitting actionable feedback
